# ScamShield

Paste an SMS or WhatsApp message (English, हिन्दी or Hinglish) to check whether it looks like a UPI/SMS scam —
and see **why**. Hybrid of a TF-IDF text model and 28 explainable fraud rules, with an evidence requirement:
a red SCAM verdict always comes with a specific reason.

Source code, method and evaluation: https://github.com/Prabhutvax/scamshield

Lost money to a scam in India? Call **1930** or report at cybercrime.gov.in.
